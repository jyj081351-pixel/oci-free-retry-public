# OCI Always Free 重试代码示例

这是独立的公开代码副本，供查看和参考。它不连接任何云账户，也不运行自动抢机。

## 包含内容

- `retry.py`：仅限 Chicago 主区域的 A1 1 OCPU / 6 GB 创建尝试、三个机房轮询及条件满足时的 E2 Micro 备用尝试。
- `test_retry.py`：免费范围、防重复创建、请求间隔、日志及同一实例升配的模拟测试。
- `retry-workflow.example.yml`：工作流参考文件，特意放在仓库根目录，不在 `.github/workflows/`，所以不会被 GitHub 自动执行。
- `requirements.txt`：固定版本的官方 OCI SDK 依赖。

## 运行边界

代码只允许一台目标实例。A1 创建后只尝试一次同机 2 OCPU / 12 GB 升配；失败或结果不明时保留实例并停止，不自动删除或重建。E2 成功后保留固定配置，不另建 A1。请求之间至少等待 60 秒；没有指定故障域。

免费资格依赖主区域、机型、官方镜像、已使用资源与服务商当时规则。缺货时没有成功时间保证；升配也可能缺货并触发重启。示例不是持续免费资格或容量的保证。

## 安全说明

本副本不包含原仓库的提交历史、私密账户凭据、原始云资源状态、完整运行日志或服务器 IP。经所有者明确授权，[HANDOVER.md](HANDOVER.md) 公开原任务的 SSH 公钥和脱敏交接摘要；不含私钥。代码中的其他凭据变量只保留名称，实际秘密值不在仓库中。

如果自行使用，请在独立的私有仓库中重新核验代码、官方免费额度和访问权限，再配置自己的加密 Secrets。不要提交 `.env`、私钥、密码或实际云配置文件。状态 Issue 会记录资源标识和公网 IP，因此不适合直接作为公开运行状态使用。

本仓库未配置 Actions 工作流或云凭据。公开代码不会影响原有私有任务。

## 本地模拟验证

在隔离的 Python 环境安装 `requirements.txt`，然后执行：

```sh
python -m unittest -v test_retry.py
```

这些测试使用模拟云服务，不创建真实资源。
